## Как работает проверка и установка обновления

1. «Проверить обновление» запрашивает `version.json` только из сети (без кэша). Новый `sw.js` помечает такой ответ заголовком `X-App-SW`; ответ без пометки при активном `sw.js` считается ненадёжным, и «актуальная версия» не показывается. Без сети — «Нет сети…», при ошибке — «Не удалось проверить обновление · Повторить».
2. «Обновить приложение»:
   1. снимает фокус с поля, сохраняет данные и проверяет, что сохранение прочиталось обратно; при ошибке — остановка с понятным сообщением;
   2. создаёт копию «Перед последним обновлением» (`-preupdate`, тот же механизм, что и раньше);
   3. если синхронизация подключена — синхронизирует. Если не удалось: «Повторить синхронизацию» или явное «Обновить с изменениями только на этом устройстве»;
   4. загружает новый `sw.js`, он скачивает файлы версии в отдельный кэш и проверяет, что `index.html` той же версии;
   5. сверяет номер загруженной версии с опубликованным;
   6. включает новую версию и перезагружает страницу один раз. После запуска показывает «Установлена версия …».
   Если загрузка не удалась, остаётся прежняя версия с сообщением об ошибке.
3. Не удаляются: `localStorage` (данные, настройки, подключение синхронизации, автокопии), чужие кэши. Удаляются только кэши более старых версий этого приложения.
4. Первый переход с рабочей версии 2026-11-21.2: её `sw.js` берёт страницу из сети, поэтому после публикации первое открытие с интернетом уже запускает 2026-11-22.1, и новая страница сама включает новый `sw.js` своей же версии без перезагрузки. Кнопка нужна начиная со следующих версий.
